# Ironhack Data Analytics Bootcamp

Documentación y ejercicios del bootcamp de Data Analytics en Ironhack (julio 2026).

## Estructura

- [`prework/`](prework) — ejercicios previos al inicio del bootcamp: tipos de datos, estadística descriptiva, pseudocódigo, estructuras de datos (listas, diccionarios), condicionales y funciones en Python.

Cada semana tiene su carpeta con un `README.md` de resumen y las subcarpetas `day1`–`day5` con los ejercicios de cada día. Despliega una semana para ir directa a sus días:
